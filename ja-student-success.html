USER GUIDE / 01

What the plugin does

JA Student Success, called Recent Success Pro in the supplied manual, stores student success stories and displays them as a card grid using one shortcode. Each card can include a photo, name, district, session badge, description, testimonial and Facebook, WhatsApp and email links.

1 · Year2 · Session3 · Student

Example: Year 2026 → Session 2025-26 → Student. Everything is managed from Recent Success in the WordPress admin. Only administrators can access this menu.

What this means

The public product name is JA Student Success. The existing Recent Success admin menu, recent-success folder, [recent_success] shortcode and rs_ database identifiers remain unchanged for compatibility.

USER GUIDE / 02

Installing and updating

First installation

1

Go to Plugins → Add New → Upload Plugin.

2

Choose the plugin ZIP and click Install Now.

3

Click Activate Plugin.

Activation creates three database tables: years, sessions and students. If no years exist, it adds the current year, next year and one starter session.

Update without losing students

1

Back up your database using your host’s backup tool or a backup plugin.

2

Replace the files in recent-success through FTP or File Manager, or use Upload Plugin → Replace current with uploaded.

3

Open Recent Success and confirm the Dashboard’s Total Students count.

Student records are in the database rather than plugin files, so replacing files does not remove them.

Important

Never click Delete on the WordPress Plugins screen. The uninstall routine permanently drops all three tables and saved settings, deleting every year, session and student. Deactivation is safe; deletion is destructive.

USER GUIDE / 03

Quick start

Complete the levels in order because each depends on the one above it.

1

Recent Success → Years: add a year, such as 2026.

2

Recent Success → Sessions: select that year, then add a session such as 2025-26.

3

Recent Success → Students: select the session, click Add New Student, complete the form and save.

4

Recent Success → Settings: select count, columns and card style, then Save Settings.

5

Use Shortcode Builder on the same page, copy the shortcode and paste it into a page or post.

After setup, daily work mainly involves adding students. Add new years and sessions when needed.

USER GUIDE / 04

Managing years

Open Recent Success → Years.

ActionHow it works
Add a yearEnter the year, such as 2026, and click Add Year. Duplicate years are refused with Year already exists.
See sessionsClick View Sessions on the year’s row.
Delete a yearClick Delete and confirm. This deletes all sessions in that year and all students in those sessions.
Important

Deleting a year cannot be undone. Take a database backup before removing one.

USER GUIDE / 05

Managing sessions

Open Recent Success → Sessions.

ActionHow it works
Add a sessionChoose a year in the top filter. The Add Session form then appears. Enter a name such as 2025-26 and click Add Session.
See studentsClick View Students on the session row.
Delete a sessionClick Delete and confirm. Every student in that session is deleted. There is no undo.
What this means

The admin session groups student records. Session Text is a separate student field that controls the public badge and shortcode session filtering. These values can differ.

USER GUIDE / 06

Managing students

Add a student

1

Open Recent Success → Students and select a session. Add New Student appears after a session is selected. The Dashboard Quick Actions also has this link.

2

Complete the form. Session and Student Name are required.

3

Click Add Student. The form reloads empty without a confirmation message. Check the Students list or Dashboard Total Students count to confirm the save.

Edit and delete

To edit, click Edit on the student row, change the fields and click Update Student. The form reloads with saved values. To delete, click Delete and confirm; deletion cannot be undone.

This version trims text that exceeds a field’s limit instead of blocking the save.

Understanding Display Order

Every student starts at 0, which sorts first. A student set to 1 appears after every student still set to 0. Students with equal numbers appear newest first. To arrange a sequence, number the featured students in order and give other students a higher number.

USER GUIDE / 08

Showing students on a page

In the block editor, add a Shortcode block and paste the code. In the Classic Editor, paste it into the text.

Shortcode Builder

Open Recent Success → Settings → Shortcode Builder. Choose count, columns and session, then click Copy Shortcode. The generated code updates when options change.

OptionMeaningExample
countNumber of students. Use -1 to display all.count="12"
colsNumber of columns, from 1 to 4.cols="4"
sessionExact match against the student’s Session Text.session="2026"

Shortcode examples

[recent_success]
[recent_success count="12" cols="4"]
[recent_success session="2026"]
[recent_success count="-1" cols="3"]

The builder accepts counts of 1–100. To show everyone, change count to -1 manually after copying. Cards sort by Display Order, then newest first.

What this means

A session filter matches Session Text exactly, including spaces. It does not select by the separate admin session ID.

USER GUIDE / 10

Backups and safety

  • Back up the database before updates, year/session deletion or large batches of edits.
  • The three tables are rs_students, rs_sessions and rs_years, with your site’s prefix, usually wp_.
  • Deleting a year, session or the plugin permanently deletes data. None has an undo inside WordPress.
  • Photos are stored separately in the Media Library. The plugin saves their web addresses. A complete backup includes both the database and uploads folder.
  • Before an update, note Dashboard Total Students and confirm the same number afterwards.
Important

Replacing plugin files is the supported update method. Do not delete the plugin as part of the update process.
