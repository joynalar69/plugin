MODULE GUIDE / 01

Install and update

What this means

Activation makes the plugin available in WordPress. Updating replaces the code while retaining the saved configuration described below. The ZIP may still use the original ja-top-bar filename; changing the display name does not require renaming internal files.

Install JA Site Toolkit from its zip file, and update it with Replace current with uploaded so nothing is lost. It needs WordPress 6.0 or newer and PHP 7.4 or newer.

First install

1

In WordPress, go to Plugins → Add New → Upload Plugin.

2

Choose ja-top-bar-1.11.4.zip and click Install Now.

3

Click Activate. A new JA Site Toolkit menu appears in the admin sidebar.

Updating to a new version

1

Go to Plugins → Add New → Upload Plugin and choose the new zip.

2

WordPress says the plugin is already installed. Click Replace current with uploaded.

3

Your settings, stats, translations and image backups stay.

Since 1.11.1, deleting the plugin also keeps your data, unless you switch on Delete all plugin data when the plugin is deleted on the Modules screen. Turn that on only when you are removing JA Site Toolkit for good.

If you are moving from JA Header Pro, delete the old plugin first. JA Site Toolkit copies its settings across on first activation.

MODULE GUIDE / 02

Dashboard and modules

What this means

Think of the dashboard as your overview and Modules as the master switches. Configure each feature on its own screen; disabling it keeps its settings for later.

Everything lives under the JA Site Toolkit menu. The Dashboard shows your traffic summary, which modules are on, and your server's details.

Menu itemWhat you do there
DashboardSee traffic, module status and system information
Top BarSet up the bar, floating buttons and Back to top (7 tabs)
StatsFull visitor numbers, charts, top pages and stats settings
LanguageChoose languages, the switcher look and how pages are translated
TranslationsCheck and correct automatic translations (shown in automatic mode only)
404 PagePick a not-found design, read the 404 log, make redirects
Global StyleSite-wide fonts, sizes and colours
UploadsUpload size limits and piece size
Media OptimizerCompress images, view savings, restore originals
ModulesSwitch each part on or off

The Big upload page is under Media → Big upload.

Switching modules on and off

Go to JA Site Toolkit → Modules, tick or untick a module, and click Save modules. A module that is off loads nothing on your site, and its settings are kept for when you turn it back on. If a module ever fails to load, the rest of the plugin keeps working and a notice names the module.

MODULE GUIDE / 03

Top bar

What this means

Content, placement and device visibility work together. An item needs a value in General, a position in Layout and permission to appear on the current device in Responsive.

The top bar is the thin strip above your theme's header for your address, phone, email, search and more. Set it up in JA Site Toolkit → Top Bar, then click Save changes at the bottom of any tab.

TabWhat it controls
GeneralThe content of each item: address and map link, phone, email, custom text, search placeholder, social icon links, a button, and shortcode items (cart, login)
LayoutWhich items show and where: drag them into the Left, Center or Right zone
StyleColours, bar height, font size, corner radius, boxed width, and the search field look
ScrollStatic or fixed bar, hiding on scroll, shrinking, and keeping a sticky theme header below the bar
Floating buttonsChat, social and Back to top buttons (next section)
ResponsiveWhich items show on desktop, tablet and phone, and the screen widths for each
AdvancedCustom CSS and JavaScript, compatibility options, settings backup

Arranging items

On the Layout tab, drag an item into a zone to show it, or back to the list to hide it. An item with empty content (for example, no email address on the General tab) does not show.

Static or fixed

•

Static scrolls away with the page.

•

Fixed stays at the top of the screen. With Hide when scrolling down on, it slides away as visitors read and returns when they scroll up. Small scrolls are ignored so it does not flicker.

If your theme's own header is sticky and gets covered, switch on Move a sticky theme header below the bar on the Scroll tab.

Search looks

Choose one of 11 search field looks on the Style tab: Classic, Minimal, Expanding icon, Command palette, Glass, Floating label, Smart search, Morphing button, Spotlight, Filters and Neon. All of them show live results as visitors type and search your site with WordPress's normal search. The Command look also opens with Ctrl+K (⌘K on Mac), and Spotlight with the / key.

Phones and tablets

On the Responsive tab, untick items you do not want on small screens. Keeping two or three items on phones keeps the bar on one line.

MODULE GUIDE / 04

Floating buttons and Back to top

What this means

Contact buttons open the destination you configure. Back to top controls page navigation. Review the mobile arrangement so buttons remain easy to tap and do not obscure content.

Floating buttons stay in a corner of the screen so visitors can reach you on WhatsApp, Messenger or any of 101 other platforms, and jump back to the top. Set them up on JA Site Toolkit → Top Bar → Floating buttons, and switch on Show floating buttons first.

Adding a button

1

Type a platform name in Add a button (for example "insta" or "linked").

2

Pick it from the list and click Add selected platform.

3

Enter your username or link. A plain username works: joynal.ar becomes your Instagram profile link. A phone number becomes a WhatsApp, Viber, call or SMS link.

4

Drag the cards to set the order, top to bottom as it shows on screen. Duplicate copies a button; Remove this channel deletes it.

Links are checked when you save. Unsafe links such as javascript: are refused, and an address like example.com gets https:// added. 82 platforms show their official logo; the others (such as LinkedIn and Slack, whose owners do not allow free use of their logos) show their initials in their brand colour.

Looks

•

Button style: 20 styles with live samples, from Classic brand colours to Modern pill (with text) and Hover reveal.

•

Hover effect: 15 effects that play once on hover. Each button can override it, and they are off for visitors who prefer less motion.

•

Layout and size: vertical stack or horizontal row, with separate sizes for tablets and phones (at least 40px so they stay easy to tap).

•

Group behind one button: shows a single chat button that opens the rest. Handy on phones.

Back to top

Open the Back to top card in the list to set it up.

Setting

Choices

Design

20 designs, including Scroll progress ring, Rocket launch, Pill with text, Neon cyber, Elegant gold and Magnetic floating

Colours

Each design's own colours, or switch on Use my colours

Position

With the other buttons, its own bottom corner, or the middle of the left or right edge

Appear after scrolling

Distance in pixels before it shows

Scrolling

Smooth (with a duration) or instant

Animation

When it appears, while waiting (plays 3 times), on hover and on click, plus duration and intensity

Size

Desktop, tablet and phone, 40–80px

Where it shows

Devices, homepage, chosen pages, content types, logged-in users, user roles

Back to top never overlaps the other floating buttons: if you pick the same bottom corner, it stays in their stack. Visitors who prefer reduced motion jump to the top instantly.

MODULE GUIDE / 05

Language and translation

What this means

The switcher is the interface; the translation method supplies the translated text. Free plugin features do not imply free third-party API usage. Provider accounts and charges depend on the selected service.

The language switcher lets visitors read your site in 47 languages. Set it up on JA Site Toolkit → Language and click Save language settings. Then drag Language switcher into a zone on the Top Bar's Layout tab, or use the [ja_language_switcher] shortcode.

1. Languages

Choose the language your site is written in, then tick the languages to offer. Search, Select all and Clear all help with long lists; drag the chosen languages to set their order. Arabic, Urdu, Persian and Hebrew pages are shown right to left automatically.

2. Where each language goes

WayBest forWhat you need
Free Google web translationTrying it out, small sitesNothing. Visitors see Google's translated copy of the page, with a small Google bar on top. Works only once your site is on its public address.
Automatic translation (your API key)Real multilingual sitesAn account with DeepL, Google Cloud Translation, Microsoft Translator, an OpenAI-compatible service, LibreTranslate or your own endpoint. Pages appear at addresses like /bn/menu/.
My own translated pagesSites already translated by handThe address of each language, using {path} for the current page, e.g. https://example.com/bn{path}
Polylang or WPMLSites using those pluginsPolylang or WPML installed; the switcher uses their languages and pages

Automatic translation in practice

1

Choose the service and paste your API key. Keys stay on the server, are shown masked, and can instead be set in wp-config.php (for example define( 'JATB_DEEPL_KEY', '…' );).

2

Click Test connection. It translates one sample sentence and shows the result.

3

Open any page with a language prefix, for example /bn/. Each sentence is translated once, saved, and reused, so you pay for it only once.

4

Correct anything on JA Site Toolkit → Translations. Edited lines become Reviewed; set Locked to keep a line forever. Reviewed and locked lines are never replaced automatically.

If the service is slow or down, the page still opens in the original language. Untranslated text is finished in the background within a few minutes. Wait for translation (default 3 seconds) sets how long a page waits.

3. Switcher look

Pick a button look for desktop, tablet and phone separately (flag and name, flag and code, globe only, and 5 more), a dropdown, searchable popup or a plain row of links, plus direction, animation and dark or light colours.

4. Visitor language

The switcher can suggest the visitor's browser language once ("View this page in বাংলা?"), switch automatically, and remember their choice. Search engines are never redirected.

MODULE GUIDE / 06

Custom 404 pages

What this means

A custom 404 changes what a visitor sees when an address is missing. A redirect instead sends the visitor to another address. Use permanent redirects for lasting moves and temporary redirects for short-term changes.

When a visitor opens a link that does not exist, JA Site Toolkit shows a friendly page instead of your theme's plain one, and still tells search engines the page is missing (a real 404). Set it up on JA Site Toolkit → 404 Page.

Design tab

1

Switch on Use a custom 404 page.

2

Click a template: Lost Signal, Paper Plane, Unplugged, Message in a Bottle, Clean Slate, Map & Compass, Missing Book, Moonlit, Brand (uses your logo) or Search Hub. The live preview on the right changes straight away.

3

Change the headline, subheadline and buttons if you like. Empty fields use the template's own words.

4

Choose the helpful extras: search field, "Did you mean…?" link, recent posts, popular pages (by page ID) and a back button.

5

Pick Inside your theme (keeps your header and footer) or Full screen, set colours if you want, and click Save 404 page.

Your theme's own files are never changed.

404 log and redirects tab

The log lists the missing addresses visitors tried, how often, and which page linked to them. It stores no IP addresses or visitor details, and ignores bots and common hacking probes.

To fix a broken link, type the right page (a full link or a path such as /menu/) next to the missing address, choose 301 (permanent) or 302 (temporary), and click Redirect. The plugin often suggests the right page for you. Redirects are listed below the log, with how often each was used.

Log entries are deleted after 90 days by default; change this under Keep entries for.

MODULE GUIDE / 07

Global Style

What this means

Blank fields preserve the theme’s choices. A palette changes colors, while typography controls fonts and text dimensions. Preview first, then save to apply your selections.

Global Style sets fonts, sizes and colours for your whole site from one screen, JA Site Toolkit → Global Style. Nothing changes on the site until you click Save style, and empty fields leave your theme's own style in place.

Quick start

A preset (Restaurant, Corporate, Education, Portfolio or Bangla site) fills in fonts and colours in one click. Use theme clears every field.

Typography

For body text, paragraphs, headings H1–H6, links and buttons, choose the font, size, phone size, weight, line height, letter spacing and capitals. The preview box shows the result before you save.

Font loading

•

Host fonts on this site (recommended): fonts are downloaded once into your uploads folder, so no visitor data goes to Google.

•

Load from Google Fonts: one combined request with only the fonts you use.

•

Do not load web fonts: system fonts only, fastest.

Colours and palettes

Click one of the 20 palettes (Modern Indigo, Ocean Blue, Royal Navy, Emerald Business, Purple SaaS, Midnight Tech, Black & Gold, Rose Modern, Teal Professional, Orange Energy, Clean Corporate, Education Blue, Forest Natural, Luxury Burgundy, Sky Startup, Slate Minimal, Cyber Neon, Warm Creative, Soft Lavender and Premium Dark) to fill all 15 colours, then adjust any of them. Palettes change colours only, not fonts.

The colours are applied to links, buttons and (if you tick Apply Background and Text colours to the whole page) the page itself. They are also available to your own CSS as variables, for example var(--jatb-color-primary).

MODULE GUIDE / 08

Big file uploads

What this means

Chunking divides a large upload into smaller requests. It helps with per-request upload limits, but does not create extra disk space or remove hosting restrictions.

Big file uploads let you add files far larger than your host's upload limit by sending them in small pieces. The default limit is 1 GB. Set it on JA Site Toolkit → Uploads and click Save settings.

Settings

1

Maximum size: the largest file anyone may upload, in MB or GB.

2

Piece size: 5 MB works on almost every host. Keep it below any proxy limit (Cloudflare's free plan allows 100 MB per request).

3

Optional: Customize by user role (for example editors 500 MB, authors 50 MB) or Customize by file type (images, video, audio, PDF, archives, documents, other).

The Limits on this server box shows your host's real limits, your new limit with pieces, and free disk space. Only file types WordPress already allows can be uploaded; the plugin never adds new ones.

Uploading

•

Media → Add New and the Media Library use pieces automatically for large files.

•

Media → Big upload is a dedicated page with a progress bar and Pause, Resume and Cancel for each file. If the connection drops, it retries on its own and carries on from the last piece received.

Every finished file is checked before it reaches your Media Library. A file whose content does not match its name (for example a script renamed to .jpg) is refused, with a Remove button. Unfinished pieces are cleaned up automatically.

Files dropped straight into the block editor do not use pieces. For files above your host's limit, use Media → Add New or Media → Big upload.

MODULE GUIDE / 09

Media Optimizer

What this means

Compression reduces file size; resizing changes dimensions. Backups allow restoration. Available formats and compression results depend on your server and the original image.

The Media Optimizer makes your images smaller on your own server, so pages load faster. Images never leave your site, and originals are backed up so you can undo it. Open JA Site Toolkit → Media Optimizer.

Running it

1

Choose a mode and click Save settings.

2

Click Optimize all images. Images are done in small batches; Pause stops after the current batch, and closing the page lets it continue in the background.

3

Read the message under the progress bar. It says how many images were made smaller and how much space was saved, and lists any that were not, with the reason.

ModeWhat it does
GentleQuality 92, removes camera data; PNG files lossless only. Almost no visible change.
Balanced (recommended)Quality 82: big savings, no visible difference for most photos. PNG photos get fewer colours only when they look identical.
AggressiveQuality 70; reduces colours in PNG photos when they still look the same; scales down images wider than the maximum width (2560px by default).
CustomYour own JPEG and WebP quality, maximum width and camera-data setting

Formats

The Your images by format table shows what you have and what happens to each type. JPEG, PNG, WebP and (where the server supports it) AVIF are compressed, keeping the same format and address. GIF is left alone so animations keep working. BMP, TIFF and HEIC originals are left alone too (their thumbnails are still compressed); convert them to JPEG or WebP before uploading for much smaller files.

A file is only replaced when the new version is smaller and passes a full check, so an image can never get bigger or broken. It works with both of WordPress's image libraries, Imagick and GD. PNG photos shrink much more with Imagick; on GD-only hosts, save product photos as JPEG or WebP for the best results.

In the Media Library

The list view gains an Optimization column showing the saving for each image, with Optimize, Re-optimize and Restore links. The Bulk actions menu has the same three choices for selected images.

Options

•

Back up original images: keep this on; it is needed to restore.

•

Optimize new uploads automatically: new images are compressed as you upload them.

•

Save new uploads' resized images as WebP: smaller thumbnails for new uploads, where the server supports WebP.

Restoring

To undo everything, click Restore all original images and type RESTORE to confirm. Images without a backup are left alone. Backups are kept in the uploads/jatb-backups folder, and are not deleted even if you remove the plugin.

MODULE GUIDE / 10

Site stats

What this means

Visitors and views measure different things. One person can create multiple views. Exclusions and browser privacy preferences mean these totals need not match another analytics service.

Site stats counts your visitors and page views without cookies and without storing IP addresses. The Traffic summary appears on your WordPress Dashboard, the JA Site Toolkit Dashboard and JA Site Toolkit → Stats.

Reading the summary

•

Online visitors: people active on your site in the last 5 minutes.

•

Visitors are counted once per person per day; Views count every page opened.

•

Today, Yesterday, Last 7 days, Last 28 days and Total, each with a green or red arrow comparing it with the period before.

The Stats page adds a 28-day chart, your top pages and the sites that send you visitors.

Status lines

Under the summary, three short lines tell you whether counting works:

•

Whether your own visits are excluded. Administrators are not counted by default, so test from a private browser window.

•

When the last visit was counted.

•

A live check: "Visitor counter is working", or the reason it is not.

What is not counted

Search engines and other bots, visitors whose browser sends "Do Not Track" or a privacy signal, quick refreshes of the same page, and the user roles you exclude. Counting works behind Cloudflare and other proxies, and switches to a backup route when a security plugin blocks WordPress's REST API.

Settings (on the Stats page)

SettingWhat it does
Count visitsPause or resume counting
Respect Do Not Track and Global Privacy ControlSkip visitors who ask not to be tracked (on by default)
Keep top pages and referrersRecord which pages and sites (on by default)
Do not count logged-inRoles whose visits are ignored (administrators by default)
Show the Dashboard widget toRoles that see the Traffic summary on the WordPress Dashboard

Export daily totals (CSV) downloads your numbers for a spreadsheet. Delete all stats clears them after a confirmation.

What this means

Paste a shortcode into a WordPress Shortcode block, rather than displaying it as ordinary text. Existing ja_ shortcode names remain unchanged after the product name update.

Shortcodes put a piece of JA Site Toolkit anywhere on a page, post or widget. Paste them into a Shortcode block.

ShortcodeShowsOptions

Backup, import and reset

On Top Bar → Advanced, under Backup and reset:

•

Download settings saves the top bar and floating button settings as a JSON file. Keep a copy after any big change.

•

Import settings loads such a file, or text pasted from one. Only the settings in the file change; anything it does not mention stays. A file that is not a JA Site Toolkit export is refused, and imports never add custom JavaScript.

•

Reset to defaults puts every top bar setting back to its starting value, after a confirmation.

The other modules (Language, 404 Page, Global Style, Uploads, Media Optimizer, Stats) keep their own settings on their own screens.

MODULE GUIDE / 12

Troubleshooting

What this means

Start with the relevant module switch, then device and page visibility, then cached content. For server-related problems, record the exact error and system information before contacting support.

Most problems come from a setting that is off, a cache showing an old page, or a host limit. Check these first.

ProblemWhat to do
Top bar or floating buttons do not showCheck the module is on (Modules), Show the top bar or Show floating buttons is on, and the page is not listed under Hide on these pages. Then clear your caching plugin's cache.
Settings disappeared after an updateYou deleted the plugin while running a version before 1.11.1. Import your downloaded settings file on Advanced, or set them up again. Update with Replace current with uploaded from now on.
Traffic summary stays at 0Read the status lines under the summary. If you are logged in as an administrator, your visits are not counted; test from a private window. A red line names what is blocking the counter.
A floating button links to the wrong placeOpen the button and save it again: links are rebuilt when you save. For Instagram, enter only your username.
An item in the top bar is missingIt needs content on the General tab, a place on the Layout tab, and a tick for that device on Responsive.
Google translation does not openFree Google web translation only works once your site is on its public address, not on a local or test site.
Automatic translation shows EnglishClick Test connection on the Language screen. A wrong key or blocked service is shown there; text not yet translated finishes in the background within a few minutes.
A large upload failsLower the Piece size on Uploads (try 2 MB), and check Free disk space. Upload from Media → Big upload rather than the block editor.
Images are "Already as small as possible"They are already well compressed. Switch to Aggressive and click Try these images again, or save PNG photos as JPEG or WebP.
"Neither GD nor Imagick" messageYour host must enable one of these PHP image libraries; ask their support.
A module shows an error noticeThe rest of the plugin keeps working. Switch that module off on Modules, and send the notice text to the developer.
