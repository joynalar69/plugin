USER GUIDE / 01

Introduction

JA Notice Board adds a custom Notice post type so you can publish announcements in categories. Visitors see a notice board with category tabs that filter instantly with no page reload.

  • Load More pagination
  • Featured notices
  • Automatic "New" badge on notices under 24 hours old
  • Expired notices hidden automatically
What this means

Requirements: WordPress 5.0 or later (tested up to 6.4). Version 1.0.0, GPL v2 or later.

USER GUIDE / 02

Installation

1

Unzip the file. Inside is the JA Notice-Board folder.

2

Upload via Plugins → Add New → Upload Plugin, or copy the folder to /wp-content/plugins/ by FTP.

3

Click Activate. A Notices menu appears in the admin sidebar.

USER GUIDE / 03

Creating notices

1

Go to Notices → Add New.

2

Enter the title and description as you would for a post.

3

In Notice Details, set an Expiry Date and tick Featured Notice if needed.

4

Tick one or more notice categories.

5

Click Publish.

  • Bulk actions and Quick Edit work from the notice list.
  • Expired notices disappear from the frontend but stay in the admin.
USER GUIDE / 04

Managing categories

1

Go to Notices → Categories.

2

Add a name, slug, description and a custom colour.

3

Hover a category in the list to edit or delete it.

What this means

You can create unlimited categories. Each one becomes a filter tab, and its colour is used on tabs and badges.

USER GUIDE / 05

Showing the notice board

Place this shortcode on any page or post:

[notice_board]
AttributeDefaultOptions
limit10Notices per page
categoryallA category slug
show_dateyesyes / no
layoutgridgrid / list
orderbydatedate / title / menu_order
orderDESCASC / DESC

Example: five exam notices, no dates, list layout.

[notice_board limit="5" category="exam" show_date="no" layout="list"]
USER GUIDE / 06

Plugin settings

Go to Settings → Notice Board for display preferences and the Delete all data on uninstall option. With Yes, deleting the plugin also removes all notices, categories and settings. The default is No, which keeps your data.

USER GUIDE / 07

What visitors can do

  • Click a category tab to filter notices instantly.
  • Press Load More to see additional notices.
  • Share a filtered view by link. The active category is stored in the URL, and Back/Forward work between tabs.
  • Use it comfortably on desktop, tablet and phone.
USER GUIDE / 08

Customisation

Template overrides

Copy a file from the plugin's templates folder into a folder named notice-board/ in your active theme: notice-board-template.php for the board, single-notice.php for a single notice.

Developer hooks

TypeHooks
Filtersnotice_board_shortcode_atts, notice_board_query_args, notice_board_categories_args
Actionsnotice_board_before_tabs, notice_board_after_tabs, notice_board_before_content, notice_board_after_content

Styles live in assets/css/frontend-style.css and admin-style.css. Override them with your own CSS so updates do not wipe your changes.

USER GUIDE / 09

Uninstalling

1

Deactivate the plugin. Your data stays in the database.

2

To erase everything, set Delete all data on uninstall to Yes first, then click Delete.
