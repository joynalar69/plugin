USER GUIDE / 01

Introduction

JA Slider is a free slider and hero-section builder for WordPress. Pick one of 100 designed templates, edit it in a visual editor and place it on any page with a shortcode. There is no Pro version, licence key or account.

What you get in version 2.0

  • 100 templates with 300 designed slides: 75 in English and 25 in Bengali (বাংলা)
  • 50 colour themes that work with every template
  • 35 bundled fonts (26 English, 9 Bengali) and 8 font pairings
  • 44 animations, 30 button styles, 25 navigation options, 16 social icon styles, 25 background options
  • Separate layout, size and visibility settings for desktop, tablet and phone
  • Automatic backups before a slider is upgraded to a newer format

Requirements

ItemMinimum
WordPress6.5 (tested up to 6.9)
PHP8.1
Editor browserA current Chrome, Edge, Firefox or Safari
What this means

JA Slider makes no external requests. All scripts, styles, fonts and icons are bundled, and nothing is tracked.

USER GUIDE / 02

Installing and updating

First install

1

In your WordPress dashboard, go to Plugins → Add New → Upload Plugin.

2

Choose ja-slider.zip and click Install Now.

3

Click Activate Plugin. A JA Slider menu appears in the left sidebar.

No npm, Composer or extra downloads are needed.

Updating to a new version

1

Upload the new ja-slider.zip in the same place.

2

When WordPress says the plugin is already installed, click Replace current with uploaded.

3

Your sliders, settings and shortcode IDs are kept. Older sliders upgrade automatically the first time you open them, and a backup is saved before the first save.

Tip If a page still looks old after an update, clear your caching plugin or CDN cache and reload.
USER GUIDE / 03

Quick start: your first slider

1

Go to JA Slider → Add New Slider. The Template Library opens.

2

Browse or search the templates. Click Preview to see one at desktop, tablet and phone size, and try a colour theme.

3

Click Use This Template. The visual editor opens.

4

Click any text in the preview to jump to its field, and type your own text.

5

Open the Buttons tab and replace each # link with your real page address.

6

Click Publish in the top-right corner.

7

Click Shortcode in the top bar to copy it, e.g. [ja_slider id="123"].

8

Edit the page, add a Shortcode block, paste, and update the page.

Tip For a full-width hero in a block theme, put the Shortcode block inside a Group block set to Full width. In a narrow column the slider uses its phone layout.
USER GUIDE / 04

Template Library

The library holds 100 ready-made sliders with three slides each. Every one is free, fully editable and works with all 50 colour themes.

Finding a template

  • Search by name or keyword, e.g. "coffee", "admission" or "বাংলা".
  • Filter by Business, E-commerce, Education, Technology, Travel, Food, Creative, Healthcare, Real Estate and Events.
  • Click the heart to add a template to Favorites. Templates you used appear under Recently used.

Bengali templates

25 templates are written entirely in Bengali with bundled Bengali fonts, including School Admission, Japanese Language, Study in Japan, Computer Training, Medical Clinic, Food Delivery and Charity Campaign. You can type any language into any template.

Switching templates later

In Template & Colours choose another template. Your text, links and images are kept. If the new template does not show some content, you are warned first and that content returns when you switch back.

USER GUIDE / 07

Phones and tablets

Every slider has its own layout for desktop, tablet and phone. Phones get a rearranged layout, not a shrunken desktop.

LayoutUsed when
DesktopScreen wider than 1024 px and the slider wider than 900 px
TabletScreen 768–1024 px, or the slider 701–900 px wide
PhoneScreen up to 767 px, or the slider 700 px wide or narrower

Tablet starts from the desktop settings and phone starts from the tablet settings. Change a value on a smaller screen and only that screen changes.

Checklist for a good phone layout

1

Size & Spacing → Mobile: use a tall ratio such as 4:5 or 9:16.

2

Typography: reduce the Mobile heading size if long words wrap awkwardly.

3

Background: set a phone focus point or a different phone image.

4

Responsive & Visibility: hide the description, a second button or the side image.

5

Navigation: phones get compact controls. You can hide arrows and rely on swipe.

Adding a slider to your site

Copy the shortcode from the editor, the Advanced tab or JA Slider → All Sliders, and paste it wherever shortcodes work.

WhereHow

Classic editorPaste on its own line
ElementorShortcode widget in a full-width section
Widgets / sidebarsShortcode or Text widget
Theme template (PHP)<?php echo do_shortcode( '[ja_slider id="123"]' ); ?>
  • Several sliders can share one page without interfering.
  • The shortcode ID never changes, even after updates or template switches.
  • Scripts and styles load only on pages that contain a slider.
USER GUIDE / 09

Backups and data safety

Older sliders are upgraded only in memory when shown, and a copy of the old version is saved before the first save in the new format.

Restoring a backup

1

Open the slider and go to Advanced.

2

Under Backups from before plugin updates, click Restore next to the version you want.

3

The slider returns to how it was. The replaced version is kept too, so a restore can be undone.

  • Copy a slider between sites: Advanced → Configuration (JSON), then paste and click Apply JSON.
  • Uninstalling keeps your sliders by default.
  • Your own slides are never overwritten by new template slides.

Old design after updateClear caching plugin, server cache or CDN
Phone layout on a computerIt is in a narrow column. Use a full-width Group or section
Text hard to read over a photoTurn on an Overlay or use the card or glass text box
Photo cut off on phonesSet a phone focus point or a different phone image
Publish is greyed outShow at least one slide on every device
